# VeloVibe AI — Команда розробки

## 🛠 Робочий процес (CI/CD)
- **Перевірка збірки:** Перед публікацією завжди запускай перевірку (`npm run build` або `npx tsc --noEmit`), щоб не зламати продакшен на Render.
- **Авто-оновлення бази даних:** Якщо в рамках завдання створюються або редагуються файли у `supabase/migrations/`, одразу виконуй `npx supabase db push` для застосування змін у живій базі Supabase. Якщо команда потребує авторизації або не може виконатись — обов'язково виводь готовий SQL-код у фінальній відповіді.
- **Автоматичний деплой коду:** Після завершення будь-якого завдання, де змінювалися файли проєкту, без додаткових запитань виконуй `git add .`, `git commit -m "<зрозумілий опис змін>"` та `git push` у поточну гілку, щоб Render миттєво почав деплой оновленого сайту.
- **Фінальний звіт:** Наприкінці кожного завдання коротко повідомляй, що база синхронізована, а код запушений на GitHub і Render розпочав оновлення.

## 📦 Технології
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4.
- **Backend:** Express.js (server.ts), Node.js.
- **Database/Auth:** Supabase (Ref: bkwjyrfmvomwhcivublf).
